# Knowledge folder: Olivia (`operations-manager`)

`operations-manager` reads this folder **before every answer**. Put documents here that are specific to this expert's work and newer or more specific than the shared research pack in `docs/`.

## What belongs here
- SOPs and checklists in use
- Daily logs, capacity and booking reports
- Client feedback and complaints

## What does not belong here
- General research that every expert needs. Put that in `docs/`.
- Passwords, API keys, bank logins or full account numbers. Never store these anywhere in the repo.
- Raw personal data about clients or staff beyond what the task needs.

## Conventions
- Name files `YYYY-MM-DD-short-title.ext` (e.g. `2026-12-02-wynwood-loi.pdf`) so the newest is easy to spot.
- Preferred formats: `.md`, `.txt`, `.csv`, `.pdf`. Add a one-line summary at the top of Markdown notes.
- If a document replaces an older one, keep the old file but add `-superseded` to its name.
- Documents here take precedence over `docs/` when they conflict, and the agent will flag the conflict.
