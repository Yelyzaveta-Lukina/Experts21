# Decision synthesis & executive memos

## Synthesis method
1. **Restate the decision** and the criteria (e.g. return, risk, time to open, fit with positioning).
2. **Collect each expert's bottom line**, key numbers and confidence labels.
3. **Find agreements, conflicts and gaps.** For each conflict, identify the cause: different assumptions, data, or values. Resolve it by (a) using the better-sourced input, (b) running both cases, or (c) escalating it as a decision for the client.
4. **Check consistency**: numbers must match across experts (the same rent, price, dogs per day). If they don't, flag and fix them.
5. **Recommend**, with conditions and the triggers that would change the answer.

## Go/no-go triggers (`docs/08-risks.md`, Estimates)
**Go** if: a zoned site at ≤ $25/sq ft all-in, build-out ≤ $90/sq ft after TI, ≥ 150 waitlist sign-ups, funding covers the build-out plus 6 months of working capital.
**No-go / rethink** if: zoning needs a contested hearing, independent all-in cost > $1M, or the price test can't support ≥ $38/day.

## Memo template
```
# <Decision>: Recommendation
**Recommendation:** <go / no-go / go-with-conditions>, in one sentence.
**Why (top 3 reasons):** …
**Key numbers:** table (labelled V/R/E)
**Options considered:** A / B / C, with trade-offs
**Risks and mitigations:** top 3–5
**Conditions / triggers to revisit:** …
**Next steps (owner, date):** …
**Expert inputs:** <agent> — one-line view each
```
Use one page where possible. Separate facts from judgement. Never hide disagreements; show them and say how they were resolved.
