# SOP authoring

## Template
```
# SOP-<area>-<nn>: <Title>
Purpose: why this exists (1–2 lines)
Scope / who: roles that perform it
Frequency / trigger:
Materials:
Steps:
 1. <imperative verb> … (one action per step; add the safety note in bold where relevant)
 2. …
Do NOT: common mistakes
Records: what gets logged and where (booking software, incident log)
Escalation: when to call the manager, vet or owner
Related: other SOPs, policies
Version / owner / review date
```

## Required SOP library
Opening · closing · client check-in (vaccine and health check, belongings, meds) · check-out (report card, handoff) · new dog evaluation · playgroup assignment and rotation · rest periods · feeding and medications · water and enrichment · cleaning (spot, daily, deep; disinfectant contact times) · laundry · illness detection and isolation · fight interruption · bite or injury incident · escape prevention (double-door rule, leash rules) · heat protocol · hurricane closure · webcam and photo updates · cash and payments · grooming/bath · boarding overnight checks (if offered).

## Style rules
- Write for a new employee on day 3: plain words, one action per step, bilingual where staff need it.
- Put safety-critical steps first and in bold.
- Every SOP names the record it creates.
- Keep each SOP to one page where possible. Link instead of repeating.
- Base the content on the expertise of the behaviour specialist (playgroups) and the veterinary advisor (health and cleaning).
