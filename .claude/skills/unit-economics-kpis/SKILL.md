# Unit economics & KPI tracking

## Core formulas
- **Revenue per dog-day (RPD)** = (daycare + add-on revenue) ÷ dog-days
- **Utilisation** = average dogs per day ÷ licensed or design capacity
- **Labour %** = (wages + burden) ÷ revenue
- **Variable cost per dog-day** ≈ supplies + card fees + the incremental labour per dog (staff-hours per dog × loaded wage)
- **Contribution per dog-day** = RPD − variable cost per dog-day
- **Break-even dogs/day** = monthly fixed costs ÷ (contribution per dog-day × operating days)
- **CAC** = marketing spend ÷ new paying clients
- **LTV** = average monthly gross margin per client ÷ monthly churn
- **Membership share** = recurring membership revenue ÷ daycare revenue

## Targets (Estimates; see `docs/04-costs.md`)
| KPI | Target |
|---|---|
| Utilisation | 75–80%+ at maturity |
| RPD | ≥ $42 including add-ons (Miami day rate $30–50) |
| Labour % | ≤ 45% |
| Occupancy % | ≤ 15–20% |
| Membership share | ≥ 50% |
| Monthly client churn | ≤ 5% |
| LTV : CAC | ≥ 3 : 1, payback < 3 months |
| Google rating | ≥ 4.8 |

## How to use it
1. State the inputs, with their labels.
2. Compute and show the formula with the numbers substituted in.
3. Compare against the targets and explain the gap and the 1–3 levers that close it (price, mix, ratio/scheduling, utilisation).
4. For a KPI dashboard, specify: metric, definition, data source (booking software), frequency, owner.
